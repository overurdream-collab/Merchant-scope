## Integrated conceptual capabilities
- find-local-clients -> prospecting (identify documented fixable gaps, do not assert ability to pay)
- competitive-intel -> competition (only comparable evidence; no unsupported competitor claims)
- audience-research -> audience (hypotheses only when supported)
- brand-voice -> content (messaging clarity, not visual identity)
- pitch-the-fix -> proposal (one evidenced fix; outreach requires sign-off)

These are **curated task mappings**, not raw prompt execution or imported scripts. No upstream code is executed; no third-party API keys are used. Automated collection remains unavailable until platform APIs and consent are configured. Each AI-generated recommendation is evidence-id validated and recorded as pending human review.

## Security review before any upstream update
Read SKILL.md, scripts, remote calls, secret access and referenced attachments for each skill. Verify pinned commit and license, compare diffs, re-run prompt-injection tests, allowlist permitted network endpoints, and reject any instruction to harvest private data or contact prospects without approval.

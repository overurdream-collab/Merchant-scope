# MerchantScope | مرصد التجار

Independent marketing intelligence agent for merchant discovery, competitor research, and evidence-based recommendations.

**Status:** early-development pilot. Do not expose publicly or use sensitive personal data. This repository is independent of Lovable.

Core design principles: preserve source evidence, never invent metrics, human review before outreach, traceable audit log, Arabic RTL support, and safe integrations only.

See implementation branch and pull requests for current code and instructions.
